# Wordvik

Wordvik er skrivehjælp til ordblinde på Mac: ordforslag, stavehjælp og oplæsning. Det hele kører på din egen Mac.

**Hent Wordvik:** [arctonia.com/wordvik](https://arctonia.com/wordvik)

## Det skal din Mac have

- macOS 14 eller nyere
- Apple Silicon (M1 eller nyere)

## Om dette repo

Her ligger kun udgivelserne af Wordvik. Hver udgivelse har en fil, der hedder `Wordvik.dmg`. Den er signeret med Developer ID og notariseret af Apple.

Linket på arctonia.com peger altid på den nyeste udgivelse.

Wordvik er lavet af [Arctonia](https://arctonia.com).
